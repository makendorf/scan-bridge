# СканМост (ScanBridge)

**Система управления сканерами штрихкодов и QR-кодов для промышленного применения.**

---

## Назначение

ScanBridge — серверное приложение для приёма данных со сканеров штрихкодов и QR-кодов, подключённых через COM-посредством COM-to-Ethernet преобразователей. Приложение обрабатывает данные и выполняет настраиваемые действия: логирование, замену символов, вставку в активное окно, экспорт в файлы/FTP/SFTP/HTTP API.

## Ключевые возможности

| Возможность | Описание |
|-------------|----------|
| **Множество сканеров** | Параллельная работа с неограниченным количеством сканеров |
| **Группы действий** | Пост-скан действия организованы в группы с привязкой к сканерам |
| **Автопереподключение** | Автоматическое восстановление при потере связи с COM-портом |
| **Определение формата** | Распознавание UUID, EAN-8/13, UPC-A, GTIN-14, Code128, GS1-128 |
| **QR-контент** | Определение типа содержимого QR-кодов (URL, JSON, WiFi, vCard) |
| **Гибкие действия** | Настраиваемый пайплайн обработки: Log, Replacement, ClipboardPaste, WindowPaste, Export, Validation, DataEnrichment, Aggregation, DatabaseQuery, Telegram, Email |
| **Веб-интерфейс** | Управление сканерами и действиями через браузер |
| **Дашборд** | Аналитика в реальном времени: KPI, графики активности, распределение форматов, статус сканеров |
| **Hub** | Центральный хаб для мониторинга нескольких экземпляров (отдельный репозиторий: [scanbridge-hub](https://github.com/makendorf/scanbridge-hub)) |

## Стек технологий

- **.NET 10** / ASP.NET Core
- **SQLite** + Entity Framework Core
- **Serilog** (логирование в БД)
- **FluentFTP** (FTP-клиент)
- **SSH.NET** (SFTP-клиент)
- **System.IO.Ports** (COM-порты)

## Быстрый старт

```bash
# Клонирование
git clone https://github.com/makendorf/skan-bridge.git
cd ScanBridge

# Запуск
cd src
dotnet run
```

Веб-интерфейс: `http://localhost:5000`

## Тестирование

```bash
dotnet test
```

Проект содержит **192 теста**: парсеры, сервисы, пост-скан действия, hub.
