# Настройка COM-портов

## Параметры порта

| Параметр | Значения | По умолчанию |
|----------|----------|--------------|
| **Name** | Любое имя сканера | — |
| **PortName** | COM1, COM2, ... | COM2 |
| **BaudRate** | 9600, 19200, 38400, 57600, 115200 | 9600 |
| **DataBits** | 7, 8 | 8 |
| **Parity** | None, Odd, Even, Mark, Space | None |
| **StopBits** | One, OnePointFive, Two | One |
| **Handshake** | None, RequestToSend, XOnXOff, RequestToSendXOnXOff | RequestToSend |
| **ReadTimeout** | 50–5000 мс | 5000 |
| **WriteTimeout** | Любое значение (мс) | 5000 |

## COM-to-Ethernet преобразователи

При использовании COM-to-Ethernet преобразователей:
1. Настройте преобразователь на нужный COM-порт
2. Укажите этот COM-порт в конфигурации сканера
3. Скорость должна совпадать со скоростью преобразователя

## Диагностика

При ошибках подключения:

1. Проверьте доступность COM-порта через `SerialPort.GetPortNames()`
2. Проверьте, не занят ли порт другим процессом
3. Убедитесь в правильности параметров (скорость, биты, чётность)
4. Проверьте физическое подключение / сеть

## Автопереподключение

При потере связи:
- Задержка: 1с → 2с → 4с → 8с → 16с → 30с (максимум)
- Максимум попыток: 10
- После превышения лимита — сканер останавливается
