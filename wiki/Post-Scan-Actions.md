# Действия после сканирования (Post-Scan Actions)

Действия выполняются последовательно после каждого сканирования. Порядок настраивается. Изменения данных в одном действии доступны следующим.

## Типы действий

### 1. Логирование (Log)

Записывает данные сканирования в БД и лог.

**Настройки:** нет

**Пример лога:**
```
Штрихкод EAN-13: 5901234123457
```

### 2. Замена символов (Replacement)

Подстановка подстрок в данных сканирования.

**Настройки:**

| Параметр | Описание |
|----------|----------|
| `Replacements` | JSON-массив правил замены |

**Формат правила:**

```json
{
  "Find": "текст для поиска",
  "Replace": "текст для замены",
  "Mode": "All|Start|End"
}
```

**Режимы:**

| Режим | Описание |
|-------|----------|
| `All` | Замена всех вхождений |
| `Start` | Замена только в начале строки |
| `End` | Замена только в конце строки |

**Пример:** Удаление префикса `SKU-` из штрихкода:
```json
{
  "Find": "SKU-",
  "Replace": "",
  "Mode": "Start"
}
```

### 3. Вставка в окно (ClipboardPaste)

Вставка данных в активное окно через Ctrl+V (WinAPI).

**Настройки:**

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `AppendNewline` | Добавить перенос строки | `false` |
| `DelayMs` | Задержка перед вставкой (мс) | `50` |

**Примечание:** Работает только на Windows. Использует WinAPI (`user32.dll`).

### 4. Экспорт (Export)

Экспорт данных в JSON/XML с настраиваемыми тегами.

**Настройки:**

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `Destination` | Назначение: `folder`, `ftp`, `sftp`, `http` | `folder` |
| `Format` | Формат файла: `json`, `xml` | `json` |
| `FilenameTemplate` | Шаблон имени файла | `{timestamp}_{scanner}_{data}` |
| `Tags` | JSON-массив тегов для экспорта | все стандартные |

#### Назначения

**Локальная папка:**

| Параметр | Описание |
|----------|----------|
| `FolderPath` | Путь к папке (включая UNC-пути) |

**FTP:**

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `FtpHost` | Хост FTP-сервера | — |
| `FtpPort` | Порт | `21` |
| `FtpUser` | Логин | — |
| `FtpPass` | Пароль | — |
| `FtpRemotePath` | Удалённая папка | `/` |
| `FtpPassive` | Пассивный режим | `true` |

**SFTP:**

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `FtpHost` | Хост SSH-сервера | — |
| `FtpPort` | Порт | `22` |
| `FtpUser` | Логин | — |
| `FtpPass` | Пароль | — |
| `FtpRemotePath` | Удалённая папка | `/` |

**HTTP POST:**

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `HttpUrl` | URL API-эндпоинта | — |
| `HttpContentType` | Content-Type | автопределение |
| `HttpHeaders` | Дополнительные заголовки (JSON) | `{}` |

**Пример HTTP-заголовков:**
```json
{
  "Authorization": "Bearer token",
  "X-Custom": "value"
}
```

#### Шаблоны имён файлов

| Плейсхолдер | Описание |
|-------------|----------|
| `{timestamp}` | Дата/время: `yyyyMMdd_HHmmss_fff` |
| `{scanner}` | Имя сканера |
| `{data}` | Распознанные данные |
| `{format}` | Формат штрихкода |

#### Теги экспорта

| Источник | Описание |
|----------|----------|
| `Timestamp` | Время сканирования |
| `ScannerName` | Имя сканера |
| `RawData` | Исходные данные |
| `ParsedData` | Обработанные данные |
| `Format` | Формат кода |
| `IsValid` | Валидность |
| `ContentType` | Тип QR-контента |
| `ParsedContent` | Распарсенный QR |
| `Custom` | Своё значение |

**Пример JSON-экспорта:**
```json
{
  "Timestamp": "2026-06-24T10:30:00.000Z",
  "ScannerName": "Main",
  "RawData": "5901234123457",
  "ParsedData": "5901234123457",
  "Format": "EAN-13",
  "IsValid": true
}
```

**Пример XML-экспорта:**
```xml
<?xml version="1.0" encoding="utf-8"?>
<ScanResult>
  <Timestamp>2026-06-24T10:30:00.000Z</Timestamp>
  <ScannerName>Main</ScannerName>
  <RawData>5901234123457</RawData>
  <ParsedData>5901234123457</ParsedData>
  <Format>EAN-13</Format>
  <IsValid>true</IsValid>
</ScanResult>
```

## Фильтрация по сканеру

Каждое действие можно привязать к конкретному сканеру. Если сканер не указан — действие выполняется для всех.

## Порядок выполнения

1. Replacement (замена символов)
2. ClipboardPaste (вставка в окно)
3. Export (экспорт)

Порядок меняется через стрелки в веб-интерфейсе.
